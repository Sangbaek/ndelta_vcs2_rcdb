# ndelta_vcs2_rcdb
A simple scripts to read and edit the Hall C N-Delta and VCS2 RCDN

## How to set up the repository

```
ssh ifarm
cd /work/hallc/alphaE/
mkdir $USER
cd $USER
git clone git@github.com:Sangbaek/ndelta_vcs2_rcdb.git
cd ndelta_vcs2_rcdb
```

## How to use the rcdb

```
python3 rcdb_reader.py -r 26352
```
